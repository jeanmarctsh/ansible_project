## Objectif

Prise en main et automatisation d'une infrastructure avec ansible pour:

    - La création d'un utilisateur ansible (rua) dédié,
    - L'utilisation de différents dossiers tels que: group_vars, host_vars pour une gestion efficace de différents paquets,
    - La gestion de différents paquets via le module apt,
    - etc...
